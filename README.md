# GrowingSpace

**A Guided VR Art Journey for Stress Relief**

GrowingSpace is a virtual reality art-making experience designed to help users unwind through guided, expressive creation. Wearing a VR headset, users sculpt and paint glowing plant forms in a calm, immersive environment - a short, self-directed art journey built for stress relief.

## Demo

A prebuilt Android/Quest demo build is available on the Releases page (demo1.apk).

### Install

Enable installation from unknown sources on your Meta Quest (or Android device). Download demo1.apk from the latest release. Sideload it (e.g. via SideQuest or adb install demo1.apk) and launch from your headset's app library.

## About

This project explores VR as a medium for guided, expressive art-making. It was featured in the MUSE Design Awards as GrowingSpace - A Guided VR Art Journey for Stress Relief.
